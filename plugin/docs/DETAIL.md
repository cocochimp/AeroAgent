# AeroAgent 机票退改插件

AeroAgent 把机票退改签业务嵌进 DeepSeek Harness：

- **订单**：查询、筛选、查看退改资格。
- **退改**：在原生对话里生成改签/退票方案；金额来自后端确定性费用引擎。
- **人工确认**：Agent 不能代确认或代支付；确认按钮只在报价卡和执行观测里。
- **预订与监控**：航班查询、待支付预订、低价监控与提醒。
- **执行观测**：流程、检索、记忆、校验、航司回执与对账。

## 使用

1. 启动 AeroAgent 后端：`uv run uvicorn app.api.main:app --port 8000`。
2. 安装本插件并在 DSH 中启用。
3. 打开 AeroAgent 导航或直接在对话里说“帮我查订单/改签/退票”。

## 配置

在插件配置中设置 `backendUrl`（默认 `http://127.0.0.1:8000`）、`identityMode`（`demo`/`token`）和 `demoUserId`。

## 边界

所有航班、订单和航司回执均为虚构数据；不连接真实航司、GDS 或支付渠道。确认与支付只允许用户在界面上操作。
